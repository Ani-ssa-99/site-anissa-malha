# Site d'Anissa Malha

Site portfolio animé, construit avec Eleventy et hébergé gratuitement sur Netlify.

- Modifier le contenu : aller sur `/admin` (connexion avec GitHub).
- Le contenu est dans `src/_data/` (accueil, parcours, portfolio, cours, astuces) et `src/blog/` (articles).
- Le style est dans `src/assets/css/style.css`, les animations dans `src/assets/js/main.js`.
- Tester en local : `npm install` puis `npm start`.
